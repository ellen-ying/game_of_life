### Welcome to the Game of Life

This is an implementation of the classic Game of Life of Conway in C++. You are welcome to download and play with it: 

\[R\] Randomly create living cells
\[C\] Kill all cells
\[F\] Increase the simulation speed
\[S\] Decrease the simulation speed
\[ENTER\] Start the simulation
\[SPACE\] Pause the simulation

You can also customise your initial state by clicking on the cells. It is really fun, for example, to intialise a glider generator. However, I don't recommend you doing it unless you are absolutely confident in your eyesight!
